# Security Policy

## Synthetic data only
This repository must never contain real tenant exports, personal information, credentials, tokens or customer data. Harbourline Group is fictional.

## Intentionally insecure material
Files under `lab-changes/` that are marked INTENTIONALLY INSECURE exist to be detected by the lab. Do not copy them into any real environment.

## Tenant labs
Labs 1.2, 7.2 and 17.2 include optional steps in a Microsoft tenant. Use a non-production environment you are authorised to change, and follow
docs/tenant-setup.md and docs/cost-and-cleanup.md.

## Reporting a vulnerability
Report suspected vulnerabilities in the lab code privately through GitHub's private vulnerability reporting for this repository
(to be enabled when the repository is published). Do not open a public issue for a vulnerability.
