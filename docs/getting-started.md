# Getting Started

1. Install Python 3.11 or later.
2. From the repository root: `python -m pip install -r requirements.txt`
3. Run Lab 0.1: `python shared/scripts/start-lab.py 0.1`, then `cd workspace/lab-0.1` and `python run.py`.
4. Open `evidence/report.md`, `evidence/result.json` and `evidence/manifest.json`.
5. Read the chapter first, then do its lab. The lab tests the decision the chapter asks you to make.

No API keys are needed. No lab calls a model or a cloud service. Three labs (1.2, 7.2, 17.2) have optional tenant steps; see tenant-setup.md.
