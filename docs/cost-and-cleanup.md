# Cost and Cleanup

Local labs: no cost, no cloud resources. Delete `workspace/` when finished.

Tenant labs: Copilot Studio agents consume Copilot Credits when used; Power Platform environments and pipelines may need licences. After the lab:
1. Delete the test agent and its flows.
2. Delete the test environment if you created one.
3. Remove test connections and any app registrations.
4. Confirm in the admin centre that consumption has stopped.
